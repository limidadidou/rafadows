Guia de Iniciação rápida ao RafaScript (RQL)

O RafaScript foi inventado no Rafadows 93 para permitir a criação instantânea de jogos de texto e lógica diretamente no terminal sem complexidade de compilação avançada.

Comandos Principais:

  • PRINT "texto" : Escreve uma mensagem no terminal.
  • VAR nome = valor : Declara uma variável (número ou texto).
  • SET nome = novo_valor : Altera o valor de uma variável.
  • INPUT "pergunta" var_destino : Pede input ao jogador e guarda na variável.
  • LABEL nome_label : Cria um ponto de salto (ancoragem).
  • GOTO nome_label : Salta diretamente para uma label.
  • IF condicao THEN ... ENDIF : Executa bloco condicional (ex: IF pontos > 10 THEN ...).
  • END : Termina a execução do jogo.
